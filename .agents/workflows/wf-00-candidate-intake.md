description: Onboard a new candidate, conduct AI intake interview, establish profile files, portfolio, and resume archetypes
---

Run the candidate intake process for onboarding a new user or updating an existing candidate profile.
Follow the full phase-by-phase instructions in `.agents/skills/candidate-intake/SKILL.md`:
1. Check permissions & setup mode (optional / decoupled).
2. Ingest career history and establish `cv_detail.md`.
3. Separate and document deep technical achievements into `portfolio.md`.
4. Capture boundaries, salary floors, and preferences in `personal_info.md` and `application_answers.json`.
5. Propose 3-5 tailored career archetypes, create `archetypes/`, write metadata, and compile PDFs.
6. Verify and register the active profile.
